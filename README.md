# 3-Symbol Tic Tac Toe (5×5 Grid)

A browser-based, single-player advanced Tic Tac Toe game on an expanded 5×5 grid with three distinct symbols.

## 🎮 Game Overview

**Play against an intelligent AI that controls two symbols (O and Z) simultaneously!**

- **Board:** 5×5 Grid (25 cells)
- **Your Symbol:** X (Blue) - Play first
- **AI Symbols:** O (Purple) and Z (Orange) - Alternate turns
- **Objective:** Get three in a row before the AI does
- **Win Condition:** First to align 3 symbols horizontally, vertically, or diagonally wins
